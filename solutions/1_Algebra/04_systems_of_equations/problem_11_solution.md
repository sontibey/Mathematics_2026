# Exercise 11. A Parameter in a System of Three Equations

Subtract equation 1 from equations 2 and 3:

$$
(t-1)y=1,\qquad (t-1)z=2.
$$

If $t\ne1$, division is valid and there is exactly one solution:

$$
y=\frac1{t-1},\qquad z=\frac2{t-1},\qquad x=1-\frac3{t-1}=\frac{t-4}{t-1}.
$$

Substituting yields right sides $1,2,3$. If $t=1$, the elimination equations become $0=1$ and $0=2$, so there is no solution. No parameter value gives infinitely many solutions.
