# Exercise 10. Detecting Dependence

The second row is twice the first: $R_2=2R_1$. Thus $R_2-2R_1=0$, a nontrivial linear relation between the rows. Replacing $R_2$ by $R_2-2R_1$ preserves the determinant and creates a zero row, so the determinant is zero. The rows are linearly dependent, the matrix has rank below 3, and it is not invertible.
