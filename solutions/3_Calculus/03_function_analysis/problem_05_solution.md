# Exercise 5. An Exponential Function with a Maximum

$$
f\prime(x)=e^{-x}(1-x).
$$

The exponential is positive, so $f$ increases on $(-\infty,1)$ and decreases on $(1,\infty)$. It has a global maximum at $(1,1/e)$, since this covers the whole real domain. As $x\to+\infty$, $xe^{-x}\to0^+$ because exponential growth dominates linear growth, so the right branch falls toward the horizontal asymptote $y=0$. As $x\to-\infty$, the function tends to $-\infty$.
