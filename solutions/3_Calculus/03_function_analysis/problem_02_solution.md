# Exercise 2. A Parabola from the Perspective of the Derivative

$$
f\prime(x)=2x-4.
$$

The derivative is negative for $x<2$ and positive for $x>2$, so the global minimum is $f(2)=-3$. Completing the square gives $f(x)=(x-2)^2-3$, which has the same vertex $(2,-3)$ since the square is nonnegative. Both methods identify the same unique minimum.
