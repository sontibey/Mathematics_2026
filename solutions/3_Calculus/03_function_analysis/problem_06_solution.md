# Exercise 6. A Logarithmic Function

The real domain is $(0,\infty)$, because the logarithm is defined only for positive arguments. All subsequent calculations must respect this restriction.

$$
f\prime(x)=\frac1x-1=\frac{1-x}{x}.
$$

The function increases on $(0,1)$ and decreases on $(1,\infty)$, with global maximum $f(1)=0$. Therefore its only zero is 1 and it is negative elsewhere. At both ends of the domain, its limit is $-\infty$.
