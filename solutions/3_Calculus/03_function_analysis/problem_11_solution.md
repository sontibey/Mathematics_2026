# Exercise 11. A Parameter and the Number of Extrema

$$
f_a\prime(x)=3(x^2-a).
$$

- If $a>0$, the critical points are $x=\pm\sqrt a$. The sign pattern is $+,-,+$, so $(-\sqrt a,2a^{3/2})$ is a local maximum and $(\sqrt a,-2a^{3/2})$ a local minimum.
- If $a=0$, there is one critical point $x=0$, but $f_0(x)=x^3$ increases through it. It is a stationary inflection, not an extremum.
- If $a<0$, $x^2-a>0$ for every $x$; there are no critical points and no extrema. The function is strictly increasing.

The transition occurs because the equation $x^2=a$ has two, one, or zero real roots as $a$ passes through zero.
