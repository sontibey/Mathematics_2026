# Exercise 6. Average Value of a Function

$$
f_{\mathrm{avg}}=\frac1{3-0}\int_0^3x^2\,dx=\frac13\left[\frac{x^3}{3}\right]_0^3=3.
$$

The point $c=\sqrt3\in[0,3]$ satisfies $f(c)=3$. The rectangle of width 3 and height 3 has area 9, equal to the area under the parabola on this interval. Continuity guarantees at least one point attaining the average; monotonicity gives uniqueness here.
