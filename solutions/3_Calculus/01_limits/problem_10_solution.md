# Exercise 10. Continuity of a Piecewise Function

The left limit is $2a+1$. The right limit is $2^2-1=3$, and because the second branch includes 2, $f(2)=3$. Continuity requires $2a+1=3$, giving $a=1$. For this value, both one-sided limits and the function value equal 3. Each branch is already continuous on its own interval.
