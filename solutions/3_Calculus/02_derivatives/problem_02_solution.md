# Exercise 2. Powers, Roots, and the Domain

$$
f(x)=2x^{1/2}-3x^{-2}+x^{3/2}.
$$

The square root requires $x\ge0$ and the reciprocal term excludes zero, so the real domain is $(0,\infty)$. By the power rule,

$$
f\prime(x)=x^{-1/2}+6x^{-3}+\frac32x^{1/2}.
$$

The derivative has the same real domain $(0,\infty)$. The endpoint zero is excluded from the function itself, so no derivative there is relevant.
