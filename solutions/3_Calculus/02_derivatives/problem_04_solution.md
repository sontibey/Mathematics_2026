# Exercise 4. A Quotient and Domain Control

The domain is $\mathbb R\setminus\{1\}$. The quotient rule gives

$$
f\prime(x)=\frac{2x(x-1)-(x^2+1)}{(x-1)^2}=\frac{x^2-2x-1}{(x-1)^2}.
$$

The restriction $x\ne1$ remains because both the original function and the derivative are undefined there. As a check, $f(x)=x+1+2/(x-1)$, whose derivative is $1-2/(x-1)^2$, equal to the result.
